# @deepseek-ai/dsh-client-ui-device-automation

[English](README.md) | 中文

设备自动化能力的浏览器 Consumer。automation 会话会获得一个标题栏快捷入口，用于打开仅包含 **文件** 与 **设备** 两个界面的紧凑详情工作区。

“文件”通过受信的 `/device-automation` Connection RPC 通道列出当前在线会话的工作目录。它可进入子目录并以只读方式打开受大小限制的 UTF-8 文件；编辑、终端、Git 与内嵌浏览器均不在功能范围内。Host 端包含关系由已配置的 `ctx.fs` Provider 判定，包括符号链接解析，因此会拒绝会话工作区之外的路径。

“设备”通过同一受信 RPC 通道请求完整截图，在替换帧解码前保留旧帧，并在每次请求完成后等待 Host 下发的间隔。浏览器文档隐藏或选中“文件”页签时会停止轮询。抓取失败后会继续重试，新连接的已授权设备无需重新打开面板即可出现。点击已解码图片内容会发送相对坐标；留白区域与加载状态不会触发点击。

## 模型体验

无；本包只贡献浏览器界面，不注册模型可见的提示词或工具。

#### KV Cache 影响

无。

## 已知限制与暂缓事项

- 文件界面仅显示纯 UTF-8 文本，尚无语法高亮、搜索或二进制预览。
- 当前 Provider 由 Host 运行时选择；浏览器尚无 Provider 选择器。

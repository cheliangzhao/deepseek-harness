# @deepseek-ai/dsh-client-ui-device-preview

[English](README.md) | 中文

仅供浏览器使用的 automation preset 预览面板，显示在共享详情栏中。其标题栏快捷入口会打开无边框的 `/api/device-preview/screenshot` 图片。浏览器文档可见时，每次图片请求完成后等待 100 ms 才发起下一次请求，因此耗时较长的设备截图不会重叠，新图片载入前会保留上一帧。图片请求失败时会显示无设备占位页，同时继续轮询，因此已授权设备出现后无需再次操作。点击显示的设备图片会将点击点映射到实际绘制的图片内容，并调用 `/device-preview/tap` Connection RPC；点击图片留白区域或图片载入期间不会产生操作。同一快捷入口可关闭预览；文档隐藏时会暂停轮询。

## 模型体验

无。该面板仅在浏览器中运行，不会到达模型请求。

#### KV Cache 影响

无；本包既不组装也不发送 provider 请求。

## 已知限制与后续工作

- 面板仅支持点击。它不保留截图、不支持滑动，也不接受键盘输入。
